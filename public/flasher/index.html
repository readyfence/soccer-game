Soccer Trainer

Install or update the trainer on an M5Stack CoreS3, straight from this page.

This browser can't talk to USB devices. Use Chrome or Edge on a Mac or PC (not Safari, not an iPad). USB access needs the secure (https) address of this page.
How to install
  1. Plug the CoreS3 into this computer with a USB-C data cable (some charging cables don't carry data).
  2. Click INSTALL and pick the CoreS3 from the list (it may be called "USB JTAG/serial debug unit").
  3. Wait about a minute until it says the install is done. The trainer restarts by itself.

If the CoreS3 doesn't show up or the install won't start, hold its RESET button (small button on the side) for about 3 seconds until the green light flashes, then click INSTALL again. Press RESET once more when it's finished.

Updating later? Don't tick "Erase".

The installer asks whether to erase the device. Only erase on the very first install. When updating, leave it unticked so Huxley's player, training history and Wi-Fi stay on the trainer.

After installing
  1. On the trainer, tap LINK (on the home screen, or under MORE). The first time, it opens a Wi-Fi hotspot called Soccer-Trainer: join it with a phone and pick your home Wi-Fi.
  2. In the game, open Trainer, pick a player from your career squad and press SEND.
